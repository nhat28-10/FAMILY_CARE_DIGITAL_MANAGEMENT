# FAMILY_CARE_DIGITAL_MANAGEMENT

Source cho hệ thống quản lý gia đình số, sử dụng NestJS, PostgreSQL, Docker Compose và Kubernetes demo.

## Tech Stack

- Backend: NestJS, TypeScript
- Database: PostgreSQL
- ORM: TypeORM
- API Docs: Swagger
- Container: Docker, Docker Compose
- Deployment demo: Kubernetes

## Repository Structure

```txt
FAMILY_CARE_DIGITAL_MANAGEMENT
├── server/                 # NestJS backend
├── admin/                  # Admin web app
├── mobile/                 # Mobile app
├── k8s/                    # Kubernetes manifests
├── docker-compose.yml      # Docker Compose setup
├── DEPLOYMENT_SETUP_GUIDE.md
└── README.md
```
